# Aplikasi Kost ku.

### Deskripsi Aplikasi Kostku
Kostku adalah aplikasi berbasis mobile yang dirancang untuk mempermudah pengelolaan dan penyewaan kost, baik bagi pemilik kost maupun penyewa. Dengan mengintegrasikan fitur-fitur modern, Kostku memberikan pengalaman yang nyaman, efisien, dan praktis dalam mengelola kebutuhan terkait kost.
